# dsh-changes-story

**Что поменялось — простыми словами.** После каждого завершённого шага агента плагин открывает в интерфейсе отдельное окно: какие файлы изменились и зачем — коротко и понятно, «как для новичка».

## Как это работает

1. Встроенный плагин `workspace-changes` в конце шага записывает событие со списком изменённых файлов.
2. `dsh-changes-story` ловит это событие, берёт список файлов и выдержки из диффов, и просит **ту же модель, что вела сессию**, написать короткий рассказ: название шага, 1–2 предложения по каждому файлу и одно итоговое предложение.
3. Браузерная часть раз в 3 секунды спрашивает у хоста свежий рассказ и открывает окно, если появился новый.

Окно также открывается вручную: **в конце каждого шага, по которому есть рассказ, появляется кнопка «📖 Рассказ»** — она открывает рассказ именно этого шага (хост хранит до 50 последних рассказов на сессию).

Если модель недоступна или ответила не JSON — показываются просто факты (`файл: +добавлено / -удалено`), окно всё равно откроется.

## Установка

Через страницу **Плагины** (Plugins) в веб-интерфейсе:

1. Откройте **Плагины** → установка по спецификации.
2. Укажите путь к этой папке (как остальные локальные плагины):

   ```
   link:S:\dsh-changes-story
   ```

   Или через CLI: `dsh plugin --profile desktop add link:S:\dsh-changes-story`

3. Перед установкой один раз выполните в папке плагина `pnpm install` (нужен `@deepseek-ai/schemastery` — уже сделано при сборке).

Хот-релоад подхватит плагин без перезапуска: иконка появится в списке, а после первого же шага с изменёнными файлами откроется окно.

## Настройки

В окне есть чекбокс **«Открывать автоматически»** — пишется в живую конфигурацию (`autoOpen`, volatile) без перезапуска. Поля `enabled` / `autoOpen` / `language` тоже доступны в настройках плагинов.

Статические поля (через `cordis.patch.yml` профиля, строка `config`):

| Поле | По умолчанию | Значение |
|---|---|---|
| `language` | `ru` | Язык рассказов |
| `maxFiles` | `12` | Сколько файлов объяснять за шаг (остальные — счётчиком) |
| `maxDiffChars` | `3000` | Символов диффа на файл для модели (0 — без диффов) |
| `maxOutputTokens` | `1500` | Лимит токенов ответа |
| `timeoutMs` | `90000` | Дедлайн одной генерации |
| `provider` + `model` | — | Явный маршрут модели вместо маршрута сессии (только вместе) |

## Ограничения

- Рассказы живут в памяти хоста и пропадают при перезапуске (как и сами сводки изменений).
- Хранится только последний рассказ (глобально и по сессии) — истории пока нет.
- Сессии субагентов не записывают изменения, поэтому рассказов по ним не бывает.
- На каждый шаг с изменениями — один дополнительный вызов модели (короткий, до 1500 токенов).

## Структура

```
lib/index.js   — хост: события сессий, вызов LLM, GET /api/changes-story.latest
lib/client.js  — браузер: опрос маршрута, модальное окно (слот shell.overlay)
cordis.patch.yml — вставляет плагин в композицию профиля
locale/        — метаданные для страницы плагинов
```
